# Family tree and civilization timeline

Open `/static/chronicle.html` on the existing local witness server. For a mounted application such as `/world`, use `/world/static/chronicle.html`. All assets and API URLs resolve relative to that mount. No engine, server, shared viewer or inhabitant prompt changes are required.

The family view groups inhabitants by recorded generation, draws biological parent-child connections, distinguishes living/deceased records, and lets the witness search or inspect parents, children and caregivers. Missing parent records are labeled rather than invented. Recorded ages are snapshot values, not inferred lifespans. The timeline filters events by category, inhabitant and public text, with event IDs, ticks, source labels and confirmed state changes. It does not turn agent statements into discoveries or fabricate milestones.

The page uses only GET snapshot and event endpoints, polling every ten seconds. Up to five 200-record pages are read per refresh; later refreshes continue scanning. Timeline rendering shows 60 matches at a time, with a Show more button. Loaded records are retained in browser memory until refresh/navigation; very long histories may need a future server-side index. Same-seed runs replaced at an equal or later tick cannot be reliably distinguished by the existing API, so reload the page after an operator switches runs.

Root state, private reflection content, internal memories and reason summaries are not rendered or searched. Public speech is assigned with textContent, never HTML. Observer controls change only the view. Backend and fixture labels distinguish mock/UI data from real model runs.

Run `node --test tests/chronicle.test.mjs` for data-transform checks. For visual QA with clearly labeled scripted lineage and events, run `python -c "import runpy; runpy.run_path('tests/chronicle_fixture.py',run_name='__main__')"` from the checkout root and open http://127.0.0.1:8010/static/chronicle.html. The fixture is not model inference and is not experimental evidence. The normal world can be launched with `python -m caitanya.server`; its empty family/history states are honest until events occur.
